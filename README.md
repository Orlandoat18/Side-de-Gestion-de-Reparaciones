# 🔧 TechFix

Portal Server-Side de Gestión de Reparaciones, desarrollado como práctica de PHP.

El proyecto permite gestionar solicitudes de reparación, identificar clientes, calcular presupuestos aplicando IVA, administrar un catálogo de recambios, controlar el inventario disponible y generar una vista HTML segura.

---

## 📋 Descripción

TechFix es una aplicación backend desarrollada con **PHP** y orientada a la gestión de solicitudes de reparación y recambios de dispositivos.

El objetivo principal es aplicar diferentes conceptos de PHP relacionados con:

- Tipado estricto.
- Configuración del entorno del servidor.
- Validación de parámetros recibidos mediante la URL.
- Gestión de respuestas HTTP.
- Tratamiento de cadenas con caracteres especiales.
- Enumeraciones respaldadas por texto.
- Programación Orientada a Objetos.
- Clases inmutables mediante propiedades `readonly`.
- Funciones tipadas.
- Argumentos nombrados.
- Cálculo de presupuestos e impuestos.
- Manipulación de arrays mediante referencias.
- Filtrado y valoración de inventario.
- Paginación de resultados.
- Búfer de salida.
- Generación de plantillas HTML.
- Protección frente a ataques XSS.
- Control de versiones mediante Git y GitHub.

---

TechFix es un portal Server-Side de gestión de reparaciones desarrollado con PHP como práctica de desarrollo web. La aplicación permite gestionar solicitudes de reparación, identificar clientes, calcular presupuestos aplicando un 21 % de IVA, administrar un catálogo de recambios y controlar el inventario disponible. Además, incorpora validación de parámetros mediante la URL, paginación de resultados, programación orientada a objetos, clases inmutables, búfer de salida y medidas de seguridad frente a ataques XSS. El proyecto está organizado en los archivos config.php, OrdenTrabajo.php e index.php, y se gestiona mediante Git y GitHub.
